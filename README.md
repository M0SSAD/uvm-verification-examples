# UVM Verification Lab

Hands-on UVM verification examples and exercises based on the book ***ASIC/SoC Functional Design Verification***.

This repository is used to build a practical understanding of the **Universal Verification Methodology (UVM)** by implementing its core verification components and gradually assembling them into complete verification environments.

## Reference

The examples and exercises in this repository are based primarily on:

***ASIC/SoC Functional Design Verification*** Book By **Ashok B. Mehta**

The implementations are written as learning exercises to reinforce the concepts presented in the book.
